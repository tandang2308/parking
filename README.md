# ParkFinder Vung Tau 🅿️

Find a parking lot near your current position — starting with **Vũng Tàu, Vietnam**.

> Status: **Sprint 0** (setup). MVP is built at zero cost and released as a free beta (Android + Web).

## Features (MVP)
- Map of nearby parking lots (motorbike / car), sorted by distance
- Lot details: price, opening hours, photos, capacity, one-tap navigation
- Parking lot owners can register, get verified and update live availability
- Vietnamese & English

## Tech stack
Flutter · Supabase (PostgreSQL + PostGIS) · OpenStreetMap · GitHub Actions · Firebase App Distribution
