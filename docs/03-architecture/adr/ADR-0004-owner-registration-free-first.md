# ADR-0004: Owner registration free in MVP, charge later

- **Status:** Accepted
- **Date:** 2026-11-24
- **Decided in:** MTG-2026-11-24-kickoff

## Context
We want parking lot owners to register with us so we can eventually charge them. At launch we have no users to offer owners; many Vũng Tàu lots are small, cash-based family businesses; charging requires a registered business + e-invoicing.

## Decision
- MVP (E6): owners register **for free**, claim/create a lot, get verified by admin, edit info and toggle live availability.
- Monetization (E7) is post-MVP. First model to try: **featured listing subscription**, paid via **VietQR bank transfer**.
- Sign-up via email/Google only (phone OTP costs SMS fees).

## Consequences
- Owners help keep data fresh and provide live availability at no cost to us.
- Need verification process to prevent fake claims (documents + photos + admin approval).
- Before E7: register business entity, set up e-invoicing, prove value with traffic stats.
