# ADR-0001: Use Scrum with 2-week sprints

- **Status:** Accepted
- **Date:** 2026-11-24
- **Decided in:** MTG-2026-11-24-kickoff

## Context
Team of Developers (Tech Lead, Devs, QA). Requirements will evolve as we learn from real data and users in Vũng Tàu.

## Decision
Use Scrum with 2-week sprints (Sprint 0 = 1 week). Add a **Product Owner** and a **Scrum Master** role. Tech Lead and QA are Developers in Scrum terms. Details in [`05-process/scrum.md`](../../05-process/scrum.md).

## Consequences
- Working, tested increment every sprint; demo on real devices.
- Plan adapts each sprint; roadmap is re-forecast from velocity.
- Requires PO availability for refinement and review.
