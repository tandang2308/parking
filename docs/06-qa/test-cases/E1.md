IDs `TC-1.x.1`–`TC-1.x.9` are the ones listed in SPEC-001 §8. Higher numbers were added for full coverage.

## Conventions

**Devices** (per test-strategy matrix): **LA** low-end Android (2–3 GB RAM) · **MA** mid/high Android · **IS** iPhone Safari (Web build) · **DC** desktop Chrome (Web build). **AE** Android emulator (mock GPS only). "All" = LA, MA, IS, DC.

**Type:** `manual` · `automated-widget` (Flutter widget/unit test, written by devs, QA reviews) · `automated-db` (SQL test against Supabase local, written by supabase-dev).

**Priority:** P1 = blocks the sprint goal or a legal/privacy rule · P2 = important behaviour · P3 = edge case / polish.

**Mock GPS points** (from SPEC-001 §8 — verify on the map before first use):

| ID | Place | Lat, Lng | Use |
|---|---|---|---|
| MP-1 | Bãi Trước | 10.3460, 107.0740 | Default centre, dense |
| MP-2 | Bãi Sau | 10.3440, 107.0960 | ≥ 60 lots → clustering, 50 cap |
| MP-3 | Tượng Chúa Kitô | 10.3265, 107.0845 | Accuracy 150 m → low accuracy |
| MP-4 | Chợ Vũng Tàu | 10.3500, 107.0820 | Narrow streets, movement target |
| MP-5 | Offshore east of Bãi Sau | 10.3400, 107.1150 | 0 lots ≤ 1 km, ≥ 1 lot ≤ 3 km |
| MP-6 | HCMC District 1 | 10.7769, 106.7009 | Outside service area |

**Test data:** seed per SPEC-001 §8 (≥ 60 lots around MP-2, mix of `motorbike` / `car` / both, 0 lots within 1 km of MP-5, ≥ 1 within 3 km of MP-5). TC-1.2.12 needs an extra condition (0 lots within 3 km) — see Q-QA-3.

**Tools:** Android: Developer options → mock location app, `adb logcat`, Charles/mitmproxy or Android Studio Network Inspector. Web: Chrome DevTools (Sensors → Location override, Network, Application → Storage, Console), Safari Web Inspector via Mac for IS. Network throttling: DevTools "Fast 4G" / Android emulator network profile.

**Fresh install** = Android: uninstall + reinstall (or Clear storage). Web: clear site data (storage + permissions) for the origin.
