# Meeting Minutes

File name: `YYYY-MM-DD-<type>.md` in a folder per sprint. Types: `kickoff`, `planning`, `review`, `retro`, `refinement`, `adhoc`.
Daily Scrums are **not** minuted unless a decision or blocker needs recording (log it in the sprint folder `daily-notes.md`).
