# Glossary

| Term | Meaning |
|---|---|
| Lot | A parking location (bãi giữ xe) for motorbikes and/or cars |
| Owner | Person/business operating a lot, registered in the app |
| Claim | Owner's request to manage an existing lot; needs admin approval |
| Verified | Lot whose owner claim was approved by admin |
| Availability | Owner-set status: `available` (còn chỗ), `almost_full` (sắp đầy), `full` (hết chỗ) |
| Last verified | Date the lot info was last confirmed (survey, admin or owner) |
| OSM | OpenStreetMap — source of initial lot data and map tiles |
| RLS | Row Level Security (Postgres/Supabase access rules) |
| PDPL | Vietnam Personal Data Protection Law (effective 01/01/2026) |
| ADR | Architecture/Project Decision Record |
| DoR / DoD | Definition of Ready / Definition of Done |
| SP | Story points |
